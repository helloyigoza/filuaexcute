# Security Policy

## Reporting a vulnerability

If you discover a security issue in this repository, please open a private security advisory or contact the maintainers directly.

Include:
- affected file(s)/component(s)
- reproduction steps
- potential impact
- suggested fix (if available)

## Scope

This repository is an educational code sample and is not distributed as a hardened production security product.

## Safe disclosure

Please avoid publishing exploit details before maintainers have had a reasonable chance to review and address the issue.
