# Contributing

Thanks for helping improve this project.

## Ground rules

- Keep changes legal, ethical, and educational.
- Do not introduce features intended to bypass anti-cheat, authentication, licensing, or platform protections.
- Keep commits focused and explain why each change is needed.

## Development checklist

1. Create a branch for your change.
2. Keep coding style consistent with surrounding files.
3. Verify the project still builds in Visual Studio.
4. Open a PR with clear summary and test notes.

## Pull request expectations

Please include:
- What changed
- Why it changed
- How you validated it
- Any known limitations
